rhobuilder#

Design the unique part of a rholo dApp, reuse the rest by rho:id, and deploy only what is new. rhobuilder is a DeepSeek Harness (DSH) app builder over the existing rhovision primitive graph: r-cash, r-sure, r-gen, r-share, r-print and r-bridge.

It guides the author through the design and reuse gate, scaffolds the standard skeleton, runs static/formal/devnet checks, and produces a deploy plan. Signing stays in the CLI with explicit gates.

First five minutes#

python3 tools/launch_dsh.py --check --json
cargo build -p rhobuilder-cli
python3 tools/launch_dsh.py --with-mcp --port 3081 web

Open the printed token URL. The dashboard shows readiness, networks, the primitive graph, the design composer, project status, evidence and testnet blockers. Read the setup hints; a setup item is not a pass. Continue with Quickstart.

What it targets#

  • Runtime: DeepSeek Harness 0.2.x, native plugin, skills and presets.
  • Chain: rholo devnet and https://testnet.rhobot.net; the mainnet profile refuses.
  • Primitives: r-cash, r-sure, r-gen, r-share, r-print, r-bridge and rholo genesis.
  • Formal: Lean 4 shallow models; proved-model is the ceiling, never a refinement.
